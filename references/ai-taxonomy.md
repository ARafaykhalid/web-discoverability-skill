# AI discoverability taxonomy

These labels are retained for vocabulary compatibility, not as a list of
official ranking factors. The registry uses `platform_status` and
`requirement_type` to prevent industry terminology from becoming a guarantee.

| Term | Classification | Engineering interpretation | Evidence boundary |
| --- | --- | --- | --- |
| AEO / Answer Engine Optimization | INDUSTRY_TERM | Clear answers, definitions, passages, and intent satisfaction | no answer-placement guarantee |
| GEO / Generative Engine Optimization | INDUSTRY_TERM | Factual, attributable, entity-consistent content suitable for retrieval | no generative citation guarantee |
| LEO | INDUSTRY_TERM | Language/entity clarity and retrieval-friendly structure | no platform factor claim |
| LLMO / Large Language Model Optimization | INDUSTRY_TERM | Accessible text, provenance, stable URLs, and machine-readable relationships | downstream model behavior is unobservable unless measured |
| MEO | INDUSTRY_TERM | Ambiguous machine/marketing-engine label; use only when project vocabulary requires it | never present as an official factor |
| VEO | INDUSTRY_TERM | Voice/video answer and media accessibility practices where applicable | no voice/video answer guarantee |
| AISEO / AI SEO | INDUSTRY_TERM | Umbrella for established SEO plus AI retrieval readiness | separate documented platform rules |
| GAIO / Generative AI Optimization | INDUSTRY_TERM | Evidence-backed content and entity clarity for generative systems | no output or traffic guarantee |
| AAIO / AI Answer Optimization | INDUSTRY_TERM | Answer structure, provenance, and user-oriented completeness | no answer visibility guarantee |
| AIO / AI Optimization | INDUSTRY_TERM | Use only as a broad label for concrete practices | avoid unsupported tactics |
| AXO / Answer Experience Optimization | INDUSTRY_TERM | Answer clarity, task completion, accessibility, and context | evaluate users and output, not a ranking claim |
| SXO / Search Experience Optimization | ESTABLISHED_PRACTICE | Intent, navigation, readability, accessibility, performance, and completion | user and repository evidence |
| XEO | INDUSTRY_TERM | Umbrella experience/answer/search vocabulary | decompose into concrete records |

Documented platform requirements, eligibility rules, technical best practices,
AI retrieval practices, industry terms, and experimental hypotheses must remain
separate in reports. `llms.txt` is an emerging optional convention, not an
official Google ranking requirement.
