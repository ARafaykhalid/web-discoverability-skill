About this fixture

The fixture is maintained inside the benchmark suite of the discoverability skill. It is not deployed anywhere and the host name in every absolute URL is reserved for documentation, so none of the addresses here resolve to a server.

Only two files are wrong on purpose. One is the crawl policy at the host root, which contradicts itself five separate ways and points at its own companion file with a path a crawler cannot resolve. The other is the URL list, which names a host that is not this one and includes an address the site itself declines to have listed.

How to read a finding here

Every finding should name either the crawl policy or the URL list. A finding against one of these four pages means the fixture has an accidental defect, and the case file next to it says so in as many words. Start from the guide if the report mentions two directives cancelling.
