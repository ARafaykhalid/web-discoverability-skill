A fixture that fails on purpose

Every page in this fixture carries exactly one class of deliberate defect and is otherwise correct. That separation is the whole point: when a check reports something on a page that was not supposed to trigger it, the report is a false positive rather than an ambiguity about which of several faults was responsible.

This page declares two title elements. A document has one title, so a second one leaves a consumer choosing between them with no rule for doing so. Nothing else here is wrong — the canonical is absolute and self-referencing, the description is present and unique, the language and viewport are declared, and every link in the navigation resolves to a page the capture holds.

Read the case file at benchmarks/cases/defective-static.json for the declared defect list and the findings each one is expected to produce.
