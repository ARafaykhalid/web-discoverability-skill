Three missing declarations

This page omits three things a served document is expected to state about itself: the meta description, the viewport, and the language of its content. All three omissions are deliberate and each one belongs to a different check, so this page is where the metadata module is expected to report exactly three findings.

The canonical is deliberately correct here. Absolute, self-referencing, and inside the head, so the canonical checks have nothing to say about this page and any finding they emit against it is a false positive.

The html element opens without a lang attribute. That is not a stylistic choice — a consumer that does not know the language of a document cannot pick a segmenter, a stemmer, or a voice for it, and it cannot tell a monolingual page from one member of a translated set.
