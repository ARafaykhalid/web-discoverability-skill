Four blocks, four different faults

The first block has a trailing comma, so it does not parse and every entity inside it is invisible. The second block parses and carries a context but declares no type, so its properties resolve to no vocabulary. Those two faults belong to the same check and two findings are expected from it.

The third block is a well-formed Organization whose logo is written as a path. A graph is consumed away from the document that served it, so a relative reference in it cannot be resolved by the consumer that reads it. One finding is expected from the absolute-URL check, and only one — every other URL-bearing property in this page is already absolute.

The fourth block is a second Organization with a different identifier. Two nodes of a type that names one real-world entity claim to describe the same thing, and nothing in the graph says which of them is authoritative. One finding is expected from the duplicate-entity check.

No block on this page carries review or rating markup, which is deliberate: the review check should report that it had nothing to inspect rather than passing silently.
