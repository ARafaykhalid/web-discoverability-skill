Three incomplete sizes and one percentage

Every image on this page carries a descriptive alternative text, so the alternative text check is expected to stay silent here and any finding it emits against this page is a false positive. What varies is the declared size.

The next image is the control. A percentage is a layout instruction rather than an intrinsic dimension, and a page that sizes an image fluidly has made a deliberate choice the check must not second-guess, so this fixture asserts it is left alone.

Three findings are expected on this page, one per image with an incomplete size, and none for the fluid banner.
