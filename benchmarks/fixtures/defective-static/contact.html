A canonical that names a visit

This canonical is absolute and its path agrees with the page's own path, so the self-reference rule is satisfied. What it also carries is a campaign parameter, which turns the canonical from a statement about the document into a statement about one arrival at it.

Exactly one finding is expected here, from the tracking-parameter check. The self-referencing check is expected to stay silent, because the parameter lives in the query string and the path comparison ignores it.

The parameter chosen is a campaign source rather than a session identifier, which makes this the most common form of the defect in the field: a marketing template writes the arrival URL into the head instead of the address of the document.
