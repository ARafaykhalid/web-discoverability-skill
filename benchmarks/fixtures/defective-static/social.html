An incomplete and self-contradicting preview block

This is the only page in the fixture that declares any preview metadata, which means the three social-preview checks judge this page and nothing else. Three findings are expected.

The block declares no og:url, so a consumer that builds a card from it has no address to attach to the card and must guess one from the request it happened to make. It declares an image with no accompanying alternative text, so the card has a picture that nothing describes. And it declares og:title twice with two different values, so the one thing a card definitely needs is the one thing the page states two answers for.

The canonical on this page is deliberately correct, and no other page carries an og: or twitter: property, so the preview checks have exactly one page to look at.
