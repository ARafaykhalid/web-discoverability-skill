#
# Stored in public/ because that is where a Vite project keeps files that must be
# served verbatim: the build copies this directory into dist/ untouched, so the

# absolute Sitemap URL as the sitemap protocol requires. Nothing here is meant to
# trip a check; this fixture is a control.
