Scheduled SQL reports, delivered where the question was asked

Meridian holds a query, a cadence, and a list of recipients. When the cadence comes round it runs the query against your warehouse and sends the result as a table, a CSV, or a message in the channel the request came from. There is nothing to install and nothing to keep running.

What this fixture is

This is a benchmark fixture, not a real service. It exists to exercise the boundary between a public marketing site and an authenticated application. The five pages reachable from the navigation above are public. Everything under /app/ needs a session, is served with a noindex directive, and is excluded in robots.txt — and that pair of exclusions is one of the faults the case file declares, because a crawler that honours the disallow never fetches the page and so never reads the noindex.

The declared defect list lives in benchmarks/cases/saas-app.json. Read it before changing anything here: a page that looks wrong is either a declared fault or an accident, and the case file is what distinguishes them.

Open the application if you already have a session. Otherwise sign in first.
